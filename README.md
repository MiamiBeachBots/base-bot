## Install
Windows

Download the Installer: Go to the WPILib GitHub releases page and download the latest installer, which is a .iso file.

Mount the Disk Image: Right-click the downloaded .iso file and select "Mount" to open it.

Run the Installer: Double-click the WPILibInstaller.exe file inside the mounted disk. Follow the on-screen prompts to complete the installation. The installer will automatically set up a separate instance of Visual Studio Code, the required Java Development Kit (JDK), and all the necessary tools.

macOS

Download the Installer: Download the latest .dmg file for macOS from the WPILib GitHub releases page.

Run the Installer: Double-click the downloaded .dmg file to open it. Then, double-click the WPILibInstaller application and follow the prompts.

Finalize the Installation: After the installation is complete, drag the newly installed WPILib Visual Studio Code application to your Applications folder or dock for easy access.

Linux

Download the Installer: Download the latest .tar.gz file for Linux from the WPILib GitHub releases page.

Extract the Files: Open a terminal and use the following command to extract the installer:

tar -xf WPILib_Linux-<version>.tar.gz


Run the Installer: Navigate into the extracted directory and run the installer from the terminal:

./WPILibInstaller


If you encounter a permissions error, run the following command first to make the file executable:

chmod a+x WPILibInstaller


Install: Proceed through the installer's prompts. It will handle the setup of all the necessary components, including Visual Studio Code, the JDK, and the WPILib tools.
